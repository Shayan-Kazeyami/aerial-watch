# Live QA checkpoint — 31 October 2026

## Environment and limitations
The standard cloud Chromium cannot create WebGL. After explicit user approval, a separate temporary Chromium profile using SwiftShader WebGL fallback renders the actual viewer. Only the local watch project is used in that profile, without logins. The normal browser and user PC are unchanged. Software throughput is not evidence of device performance. Browser DevTools is blocked by organization policy; no bypass was attempted.

## Visually observed
- The authored B face actually renders in WebGL; this is not the fallback poster.
- Original solid-face comparison restores the ivory original dial.
- Interior view changes camera to the reverse movement; after the layout fix, the control grid remains visible in place.
- Glass can be hidden and restores clarity for direct face inspection.
- Quality choice changes from Smooth to Sharp and the active button updates.
- Crown pull changes label/state to Pulled, moves the crown outward and pauses motion.
- `?quality=efficient&paused=1` starts the viewer paused in the selected lighter mode.

## Issues found and changes under test
- Interior guide displaced the bottom control area. Duplicate guide content is now suppressed; power-path control moved to the always-visible appearance group. Camera rail retains equivalent focus actions.
- Crown action text had poor contrast. Its foreground/background contrast is corrected.
- Premium palette now uses neutral bearing and steel wheel-plate finishes to match approved B; no decorative blue jewels. Source meshes remain unchanged.
- Added bounded PNG encoding and useful progress/error reporting, with regression coverage for null, thrown and absent callbacks.
- Download anchors are attached during activation and object URLs live for 60 seconds, with lifecycle cleanup.
- Added a reproducible capture-provenance generator to include all new runtime files. It identifies source bytes, not visual or mechanical correctness.
