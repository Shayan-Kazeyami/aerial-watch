The standard cloud Chromium cannot create WebGL. After explicit user approval, a separate temporary Chromium profile using SwiftShader WebGL fallback renders the actual viewer. Only the local watch project is used in that profile, without logins. The normal browser and user PC are unchanged. Software throughput is not evidence of device performance. Browser DevTools is blocked by organization policy; no bypass was attempted.
